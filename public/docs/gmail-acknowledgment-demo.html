Gmail Acknowledgment Draft Automation

Published demo · Successful run and matching draft shown

A small workflow that prepares an acknowledgment for review when a new email arrives. Built with Gmail and Zapier using the author’s free-plan setup.

The working workflow

  1. 01 · Gmail
    Receive a new email
  2. 02 · Gmail
    Create an acknowledgment draft
  3. 03 · Human review
    Review the draft before sending

The human review stage happens in Gmail, outside the two-step Zap. The workflow uses a fixed template; it does not generate an AI reply or send a message automatically.
