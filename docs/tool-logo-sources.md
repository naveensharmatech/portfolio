# Tool logo sources

All tool cards use equal visual prominence; no primary or secondary categories.
API integration and webhooks remain capabilities, not branded tool cards.
Python, JavaScript and Node.js retain the AI-assisted qualifier.

SVG assets are unaltered brand marks from the repositories below, except the monochrome Zapier and HubSpot SVGs which have their published brand color applied. Brand ownership remains with each respective owner. Beautiful Soup uses the original public-domain John Tenniel illustration displayed on its official project homepage, rather than an invented company logo.
